# Локальные сервисы разработки

`local.sqlite3` создаётся автоматически при запуске приложения, если
`APP_LOCAL_DEVELOPMENT=true`. Файл и его журналы не коммитятся: они
содержат только локальное состояние разработчика.

`schema.sql` — идемпотентный шаблон первичных таблиц. Добавляйте прикладные
таблицы и миграции осознанно, не изменяя уже применённые структуры задним числом.

После активации `.venv` базой можно управлять без HTTP-сервера:

```bash
python local_services/manage.py init
python local_services/manage.py status
python local_services/manage.py reset
```

`reset` удаляет локальный файл БД и заново применяет `schema.sql`.
